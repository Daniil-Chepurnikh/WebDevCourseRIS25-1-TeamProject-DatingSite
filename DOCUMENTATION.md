### Правила ведения репозитория на GitHub

Для наиболее удобной, безопасной и качественной работы наша бригада определила следующие правила:

- не коммитить в базовую ветку `main`;

- каждый работает в своей ветке(см. в списке "Состав бригады");

- не вливать `PR` без согласия всех участников;

- подробно описывать в `PR` всё, что сделано;

- ведение канбан-доски в `Projects` в репозитории;

- создание полноценного `README.MD`;

- во всех `issue` писать внятное и подробное описание;

- для специфических и/или сложных задач будут создаваться отдельные ветки возможно на несколько участников;
